# 在庫ヒートマップ比較

未使用車専門店の在庫一覧ページを読み込み、価格(縦軸) × 年式または走行距離(横軸) の四象限グラフで在庫の集まり方を、自社と他社で横並びに比較するWebアプリ。
走行距離による車両区分（未使用車／チョイ乗り車／中古車）の台数も店舗ごとに集計する。

## 起動
**フォルダ内の `start.bat` をダブルクリック**するだけで起動し、ブラウザが自動で開く。
- 必要なライブラリが無ければ自動でインストールする
- ポート8000が使えないとき（他のアプリが使用中・Windowsの予約ポート）は空いているポートを自動で選ぶ
- 開いた黒いウィンドウはアプリ本体なので、使っている間は閉じない

PowerShellから起動する場合は、どのフォルダからでも次で起動できる。
```
python C:\(展開した場所)\inventory-heatmap\run.py
```

## 画面が開かないとき
| ブラウザの表示 | 原因 | 対処 |
|---|---|---|
| 「接続が拒否されました」(ERR_CONNECTION_REFUSED) | アプリが起動していない、または黒いウィンドウを閉じた | `start.bat` で起動し、ウィンドウに出たアドレスを開く |
| 「アクセスが拒否されました」(ERR_ACCESS_DENIED) / HTTP ERROR 403 | セキュリティソフトやプロキシがローカル通信を止めている | アドレスの `127.0.0.1` を `localhost` に変えて開く。プロキシ設定で「ローカル アドレスにはプロキシ サーバーを使わない」をオンにする |
| 起動時に「WinError 10013」 | ポート8000がWindowsに予約されている | `start.bat` / `run.py` で起動すれば別ポートを自動で使う |

## 使い方
1. 左の「自社」に社名と在庫一覧URLを入れる
2. 「他社」に比較したい店舗を入れる。「＋ 他社を追加」で何社でも追加でき、× で削除
3. 「比較する」で各社を並行して読み込み、読み込めた店舗から順に四象限グラフが並ぶ
4. 上部で表示を切り替え（再読み込みなしで即時反映）
   - 横軸: 年式（右ほど新しい） / 走行距離（右ほど多い・対数目盛り）。縦軸は価格（上ほど高い）
   - 色の濃さ: 台数 / 構成比（在庫規模が違う店舗同士は構成比が比べやすい）
   - 滑らかさ: 価格方向（縦）のぼかし幅
   - 車両を点で表示: 1台ずつの点（マウスを乗せると車名・価格・年式・走行距離）
5. 「四象限の境界」で区切りを変更できる（価格◯万円以上を上、年式◯年以降／走行距離◯km以上を右）
   - 初期値: 価格と年式は全店舗をまとめた中央値、走行距離は未使用車の上限の100km
6. 各象限の台数・比率はグラフの四隅と、下の「象限ごとの比較」表で確認できる
7. 車両区分ごとの台数は、各パネル上部の帯グラフと、下の「車両区分ごとの台数」表（全店舗の合計つき）で確認できる

## 車両区分の定義（走行距離）
| 区分 | 走行距離 |
|---|---|
| 未使用車 | 100km未満 |
| チョイ乗り車 | 100km以上 10,000km未満 |
| 中古車 | 10,000km以上 |
| 走行距離不明 | 走行距離を読み取れなかった車両 |

定義は `static/index.html` の `CATS` で変更できる。横軸を走行距離にすると、グラフ上部に区分の境界（100km・10,000km）が点線で表示される。

全店舗で軸・境界・色の目盛りを揃えているので、そのまま比較できる。
自社のパネルは横スクロールしても左端に固定される。左の入力欄は「‹」でたたんで、グラフを広く使える。
入力内容と入力欄の開閉状態はブラウザに保存され、次回も残る。
各パネル右上のカメラアイコンで画像として保存できる（提案資料用）。

## 仕組み
- `scraper.py`: ページ取得(SSRF対策) → 1台分のカードを抽出 → 価格・年式・走行距離を判定
  - カード: 「価格を含む同じ形の要素が繰り返し並んでいる」部分を一覧とみなし、その1要素を1台とする（1台に本体価格・支払総額・諸費用など価格が複数あっても崩れない）
  - 全角英数・㎞ は半角にそろえてから判定
  - ページ送り: rel=next → 「次へ」系(テキスト/aria-label/class) → ページ番号リンク → URLのpage番号+1 の順で次ページを探す
  - 年式: 「年式 2024」「年式(初度登録) R6」のようなラベル付きを優先。西暦・和暦・2024(R06)・2024/04 にも対応。車検・掲載日の年や「5年保証」は除外
  - 走行距離: 「走行 20km」「走行距離 20」(単位が別要素)「0.1万km」「1.5千km」「10㎞」等。燃費(km/L)・航続距離・保証距離は除外
- `main.py`: `/api/analyze` (FastAPI)。車両ごとの価格・年式・走行距離などを返す
- `static/index.html`: 各車両を価格・縦軸方向にガウス分布で広げて足し合わせる(2次元のカーネル密度推定)ことで、区切りのない連続的なヒートマップを描き、境界線で四象限に分けて集計

## 調整ポイント
- 年式・走行距離が「不明」になる場合は、パネル下の「車両データを見る」で抽出テキストを確認する
- ページ送りがJavaScript/POSTのサイトは未対応 (その場合は Playwright 導入を検討)
- 対象サイトの利用規約・robots.txt を確認の上、取得間隔(`delay`)を守って利用すること
